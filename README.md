# Action 5 Pro 相机素材同步

供个人使用的原生 macOS 应用：通过蓝牙准备相机热点，Mac 手动接入 WiFi 后浏览、预览并下载相机原片。最低 macOS 15，当前构建目标为 Apple 芯片 Mac。

## 构建与启动

本机需要 Xcode；应用使用系统框架，不需要安装额外运行时。

```sh
zsh scripts/build.sh
open .build/DerivedData/Build/Products/Debug/WiFiSync.app
```

也可以打开 `WiFiSync.xcodeproj`，选择共享的 `WiFiSync` scheme 构建。使用本机 ad-hoc 签名，无需付费开发者账户。修改源代码后重新构建可能需要重新授权蓝牙或本地网络。

权限验收通过 Finder 或上面的 `open` 命令启动 `.app`；直接运行应用内部二进制不能证明正常启动时的权限行为。

## 使用步骤

1. 相机已经激活，开机并靠近 Mac；退出手机上的 DJI Mimo，避免占用相机会话。
2. 打开应用，允许蓝牙访问，点击“扫描 Action 5 Pro”，选择相机。首次连接在相机屏幕确认。
3. 应用显示热点名称；在 Mac 系统 WiFi 菜单中连接该热点。密码可在应用内显示或复制。
4. 点击“已连接热点，读取素材”，允许本地网络访问。两种存储的素材分批显示；“同步全部新增”在完整扫描后启用。
5. 选择保存目录；点击缩略图预览，勾选素材后下载，或同步全部新增。
6. 在“同步队列”暂停、恢复或重试，已完成的文件可在 Finder 查看。

同步期间 Mac 可能无法通过原 WiFi 上网。结束后点击“断开相机”，自行切回原来的 WiFi。

## 素材与传输行为

- 下载原始文件，保留相机上的素材，不进行转码或压缩。
- 默认保存到 `所选目录/拍摄日期/SD 卡或内置存储/原文件名`；无有效拍摄日期时归入“日期未知”。同名目标文件保留双方并增加编号。
- FAT 日期没有时区，应用按相机记录的年月日整理，不自动修改相机时钟。
- 素材身份包含相机、存储来源、完整路径；同步版本还包含清单大小和拍摄时间。同步记录保存在应用沙盒的 Application Support 下。
- 视频优先使用 `.LRF` 低清代理预览。无代理或原生播放器不支持时，显示下载原片操作；预览缓存不计作已同步。
- 素材卡片和同步队列均提供“预览”按钮；已同步素材在重启后恢复到素材库，可以离线预览。视频使用 AppKit 原生播放器，提供播放、暂停和从头播放操作。
- 原片分块直接写盘，内存占用不会随视频大小增长。`.part` 临时文件完成且长度正确后计算 SHA-256，保存提交凭据，再改名并提交同步记录。若改名后应用意外退出，下次启动通过长度和校验值恢复完成状态。
- 续传检查 `206` 和 `Content-Range`。相机忽略 Range 返回 `200` 时从头下载，避免重复追加导致文件损坏。
- 退出或暂停后保留未完成任务；重新启动后手动恢复。已有目标文件不会被覆盖。
- 完整分页失败时保留已经显示的素材，但不会启用同步全部新增。未确认空存储的响应也不会被当作完整列表。

## 测试

```sh
zsh scripts/test.sh
```

测试覆盖 DUML 校验及分帧、UDP 窗口应答、分块丢失、双存储身份、超过 45 项分页、CompositePack 布局、日期、HTTP 范围响应、中断恢复、SQLite 重启、目标冲突与 SHA-256。HTTP 测试使用受控 URLProtocol 响应，不访问真实相机。

真实参考夹具来自 Xtra 同系列布局，仅验证解析器，不代表本应用已通过 Action 5 Pro 实机验收。真实相机固件、CoreBluetooth 系统协商 MTU、热点时序和 LRF 格式兼容性必须实测。CoreBluetooth 不提供应用指定 ATT MTU 的接口；应用按系统写入上限分片。

## 真机验收

在“连接验证”页查看固件和完整扫描状态。验收结果记录在 `docs/真机验收.md`。

1. 第一次授权、拒绝后重新授权、首次配对和后续重连。
2. SD 卡和内置存储分别读取；至少一侧超过 45 项，检查照片组是否展开，核对相机或 USB 文件数量。
3. 照片预览、视频代理播放、没有代理的视频提示；预览不会触发整段大视频自动下载。
4. 下载一张照片和一个视频，点击队列“对比 USB 原片…”选择同一原片，检查 SHA-256 一致。
5. 大视频下载期间暂停、断开热点、重新连接后恢复；退出应用再恢复，检查最终 SHA-256。
6. 检查磁盘不足、目录不可用、空存储和无 SD 卡时的反馈；失败任务不得显示为已完成。

## 工程维护

- `Sources/Core`：协议、蓝牙、媒体会话、缓存、下载和 SQLite。
- `Sources/App`：中文连接向导、素材库、预览、同步队列与验收入口。
- 新增 Swift 文件后使用 `python3 scripts/generate_project.py` 更新提交的 Xcode 工程。
- `.gitignore` 排除构建、素材、缓存、个人配置及凭据。诊断信息不包含热点密码，复制分享前可检查文件名。
- 开源协议参考和许可见 `THIRD_PARTY_NOTICES.md`。
